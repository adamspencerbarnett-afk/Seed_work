# Seedwork 0.7.0

**An AI-assisted world-building toolkit by Adam S. Barnett.** Create a world, assemble reusable models, apply weather and seasons, inspect the result, and develop a playable Three.js prototype. The toolkit provides deterministic tools and an editor; it does not contain an AI model or promise to generate a finished game from a sentence.

For a ChatGPT handoff, read **[START_HERE_CHATGPT.md](START_HERE_CHATGPT.md)**. For an existing game, read **[docs/EMBEDDING.md](docs/EMBEDDING.md)**. Machine-readable capabilities are in `seedwork-capabilities.json`; the exact 42-tool catalog is in `tools.manifest.json`, and the offline plan schema is in `plan.schema.json`.

## Run locally

Install Node.js 22 or newer separately and use a desktop browser with WebGL. Extract the ZIP into a new folder, then run:

```sh
cd seedwork
node server.mjs
```

Open `http://127.0.0.1:4173/`. Windows also has `start.cmd`; macOS/Linux have `start.sh`. Keep the terminal running. There is no npm installation, frontend build, Python environment, package download, paid API, or account needed to use the bundled tools, editor, models and environment gallery. Node and the browser themselves are not bundled executables.

The editor is at `/`, the weather gallery at `/environment/`, and the existing-game integration example at `/host/`. Settings and edits live in `.seedwork/`. Do not publish that folder: it includes local credentials and user data.

## Build through a file-based AI workflow

```sh
node seedwork.mjs doctor
node seedwork.mjs context
node seedwork.mjs new --plan examples/plans/autumn-settlement.json --out ../my-world
cd ../my-world
node server.mjs
```

The new folder is self-contained application source with its generated project. First launch imports `project/start.seedpack.json`; later launches preserve local edits. Use **Play world** to explore. The CLI returns data-validation results, not a claim that a browser or gameplay review occurred.

`node seedwork.mjs plan --input plan.json --out ../world-files` produces portable world files without duplicating the application. `node seedwork.mjs model --recipe recipe.json --out ../new-model` compiles an individual model. `node seedwork.mjs tools` prints the actual tool schemas. See [the AI workflow](docs/AI_WORKFLOW.md).

## This release's boundaries

This package is based on the available **0.6 environment preview**, whose underlying integrated source was 0.4. The separate **0.5 coastal/Clearwater water archive was not available**. This release does not claim to include those advanced providers. The basic earlier world water remains.

The user-supplied AI 3D Chat Kit had no verified redistribution permission, so its source, applications and Python dependencies are **not distributed**. An independently written Node compiler replaces the native modeling backend. All seven bundled native models were rebuilt using this compiler and the original Seedwork-authored recipes. These are a new visual baseline, not pixel-identical conversions of the old kit output. Legacy sculpt, stamp, decal and unsupported primitive fields fail explicitly; they are never silently discarded.

Three.js **r140 remains pinned**, not the latest Three.js release. A renderer migration is a separate compatibility pass. Surfaces and models are procedural, not scans. Snow is a shader coating, fog is not a volumetric atmosphere, collision is approximate, and environmental effects do not automatically implement swimming, icy physics or multiplayer.

The SDK accepts the host's compatible Three.js namespace. It does not add a second game loop or take over controls. The supplied host example is not an adapter for every arbitrary game.

## Quality and performance

No automatic geometry decimation, texture resizing, lower-detail substitution or render-resolution reduction is enabled. Repeated resources and cached build results are reused. Exact vertex compaction preserves triangle-corner attribute bytes, winding, material values, image bytes, samplers and transforms against the new compiler's reference GLB.

A data-equivalent asset is not a universal frame-rate or cross-GPU pixel-equality guarantee. See [docs/TESTS.md](docs/TESTS.md) for the checks actually run, including failures and limitations. Visual authoring changes create a new baseline; optimization is checked against that baseline.

## ChatGPT is not automatically connected

Uploading this ZIP supplies files, not a live tool installation. A capable chat can inspect the source, write a plan and return a modified project. It cannot thereby access a browser or `localhost` server on the user's computer. Archive extraction, code execution and downloadable output depend on the tools available in that conversation. The included stdio MCP bridge is for compatible local clients; no hosted ChatGPT app or remote MCP deployment is bundled.
